# Evidence

Curated evidence from real runs against the CoreServ demo app. Every scenario folder is a verbatim copy of one run directory from `runs/` (run log, `result.json` or `trace.json`, masked screenshots and observation dumps, intervention files); the E1 folders also hold their compile's verification run under `verification/`, and `artifacts/` holds copies of the files in `capabilities/`. Nothing was edited by hand. Member numbers, names, account numbers and amounts are masked in logs (`***77`, `[financial]`) and screenshots; outputs are masked in `result.json`. Paths inside `result.json` still point at the original `runs/<runId>/` location. Hashes differ along the way on purpose: a verification run replays the draft before `provenance.verifiedWith` is added, the compile report records the hash after it, and the reviewer's outcomes (version 1.1.0) change it again.
